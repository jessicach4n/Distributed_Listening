# Distributed_Listening
Distributed Listening with Mobile Phones Project for CART 470

## How to Run
1. Clone the repository to your local machine.
2. Navigate to the project directory.
3. Install the required dependencies by running:
   ```bash
   npm install
   ```
4. Start the server by running:
   ```bash
   cd server
   node index.js
   ```
5. Open the `client/index.html` file in a web browser to connect to the WebSocket server and receive audio channel information.
